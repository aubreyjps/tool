# GeoKit 地理工具箱

一个可完全离线使用的单文件 HTML 地理工具箱。无需安装、无需服务器、无外部依赖，直接用浏览器打开 `index.html` 即可。

左侧工具栏支持一键折叠：展开时显示完整工具名称与说明；折叠后收为窄边栏，仅保留品牌标记和工具图标。折叠按钮位于侧边栏中部偏右，默认隐藏，鼠标移到附近时出现，点击即可折叠或展开。折叠状态只保存在本机浏览器中。

## 工具

### 01 坐标系转换

- 支持 WGS-84、GCJ-02（火星坐标）、BD-09（百度坐标）三者互转。
- 支持批量经纬度文本，也支持直接粘贴 WKT 几何进行整段转换。
- WKT 支持 `POINT`、`LINESTRING`、`POLYGON`、`MULTI*`、`GEOMETRYCOLLECTION`。
- 可选 4–8 位小数输出精度。
- 支持复制结果、下载 `.txt` / `.wkt` 文件。

### 02 围栏格式转换

- 输入格式：对象数组、坐标对数组、逗号/分号分隔、按行分隔、WKT、GeoJSON。
- 输出格式：经纬度数组（可选对象数组/坐标对/分号/换行）、WKT、GeoJSON。
- 自动识别输入格式，WKT 与 GeoJSON 可完整往返转换。
- 支持多边形、折线、点集、多环多边形、多面与几何集合。
- 自动闭合多边形，并显示顶点数、面积、周长、包围盒与中心点。
- 内置离线 SVG 空间预览。

## 经纬度数组输入示例

```js
[{lng: 116.397, lat: 39.916}, {lng: 121.473, lat: 31.230}]
```

```js
[[116.397, 39.916], [121.473, 31.230]]
```

```text
116.397,39.916;121.473,31.230
```

```text
116.397,39.916
121.473,31.230
```

数组顺序为 **经度 lng、纬度 lat**，也兼容 `lon`、`longitude`、`latitude`、`x`、`y` 字段。

## 说明

- 国内 GCJ-02 偏移使用公开算法；WGS-84 → GCJ-02 为近似纠偏，GCJ-02 → WGS-84 使用迭代反算。
- BD-09 反向转换在标准公式基础上做了迭代校正，以获得更稳定的往返精度。
- WKT 输入中的 `SRID` 前缀会被移除；Z / M 维度会按二维经纬度处理。
- 所有计算和文件读取都在浏览器本地完成，不会发起网络请求。

推荐使用较新的 Chrome、Edge、Firefox 或 Safari。
